# Legacy v1 results (April 2026 preprint)

Outputs of the original two-cohort analysis in `notebooks/01-14`, committed on
2026-04-01 and reported in the April 2026 preprint. That analysis used a
different seven-pathway gene definition, a binary "death or progression within
5 years" outcome, and cohorts restricted to patients with a defined 5-year
outcome (censored-before-5-years patients excluded). The legacy TCGA-BRCA set
(n = 213) also contained 37 solid-tissue-normal and 3 metastatic samples, and
the legacy GSE96058 set (n = 1,483) contained 60 technical replicates.

None of these files feed the current analysis. They are kept so the preprint
results can be traced.
